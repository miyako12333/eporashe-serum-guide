# EPORASHE 美容液の選び方・徹底比較LP（確認用）

GitHub Pages プレビュー用。index.html をリポジトリのルートに配置。

## プレビュー設定
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。

## 注意
- 公式商品画像3点は外部CDN参照。ZIPには含まれていないため、ネット環境や参照先の変更により表示されない可能性があります。
- 生成画像の人物カット1点および図解SVG1点を同梱。以前のLP全体モックアップは架空ボトルを含むため採用していません。
- 現段階で公式の複数美容液併用順序・実物テクスチャー・在庫・薬事確認およびecforce内での実機動作は未承認。
- GitHub Pagesで確認後、ecforceの利用箇所に応じて既存テーマへの組み込みまたはLPテンプレート化が必要です。
